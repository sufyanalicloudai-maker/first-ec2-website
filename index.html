What I learned building it

Three lessons from getting my first website online.

A server is just a computer you rent and log in to.

I connected over SSH, installed Nginx, and put my own file in the web folder.

Open only the ports you need

SSH on 22 for me, HTTP on 80 for visitors. Everything else stays closed.

Logs explain what went wrong

When a page fails to load, the Nginx error log usually says why.

The commands behind this page

Run on Amazon Linux 2023, over SSH.

# install and start the web server
sudo dnf install nginx -y
sudo systemctl enable --now nginx

# check the config, then publish changes
sudo nginx -t
sudo systemctl reload nginx
